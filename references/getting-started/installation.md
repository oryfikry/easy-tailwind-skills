# Installation

Get started with Tailwind CSS by installing it with the tool that fits your project. The Vite plugin is the most seamless route for frameworks like React Router, SvelteKit, Nuxt, Laravel and SolidJS.

Source: https://tailwindcss.com/docs/installation

## Installation methods

- [Installing Tailwind CSS with Vite](../installation/using-vite.md) — Installing Tailwind CSS as a Vite plugin is the most seamless way to integrate it with frameworks like Laravel, SvelteKit, React Router, Nuxt, and SolidJS.
- [Installing Tailwind CSS with PostCSS](../installation/using-postcss.md) — Installing Tailwind CSS as a PostCSS plugin is the most seamless way to integrate it with frameworks like Next.js and Angular.
- [Tailwind CLI](../installation/tailwind-cli.md) — The simplest and fastest way to get up and running with Tailwind CSS from scratch is with the Tailwind CLI tool. The CLI is also available as a standalone executable if you want to use it without installing Node.js.
- [Play CDN](../installation/play-cdn.md) — Use the Play CDN to try Tailwind right in the browser without any build step. The Play CDN is designed for development purposes only, and is not intended for production.
